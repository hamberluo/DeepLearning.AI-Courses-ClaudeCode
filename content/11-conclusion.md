# 结语

恭喜你走到这里！

你已经学会了怎么用 Claude Code 去**探索、测试、重构和调试**代码库。

想把 Claude Code 用到极致，记住几点：给它**清晰的指令**、讲清**上下文**、把它指向代码库里**相关的文件**。别忘了把你的**代码库规则**写进 `CLAUDE.md`，以及任何你希望 Claude Code 记住的、关于你项目的信息。

也可以考虑**扩展 Claude Code 的能力**，把它连上像 Playwright、Figma 这样的 MCP 服务器。

谢谢你一路同行，迫不及待想看看你会用 Claude Code 创造出什么。
